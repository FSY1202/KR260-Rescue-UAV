# 相对当前板端快照的整理改动

本次操作不修改原工程、不重启板端服务。以下改动只进入交付源码副本；实际板上仍是原部署版本。

- 补齐项目结构、依赖、构建/安装/测试/性能/许可文档和 CI。
- Vivado 仿真脚本改用 `VIVADO_BIN` 或 `-VivadoBin`，删除个人磁盘路径。
- 删除 RGB2DVI 包装 XML 中历史 ARCHIVE_LOCATION 标签的开发机路径；HDL、接口、时钟约束和版权头保留。
- 安装脚本在桌面 drop-in 前补装基础 `gesture-web.service`，避免新镜像缺失该服务；完整安装尚未在板上重跑。
- 门框 G1/G2 标记放到新复制的显示帧绘制，不再反复写入累积点云底图，避免重画历史影响边缘；路线与显现逻辑不变。
- 状态栏模式文字绘制后保持该局部区域 alpha=255，修正 OpenCV 5 的透明度回归；板上 XRGB 不使用该 alpha，但导出 PNG 应保持不透明。
- 轻微姿态回归上限收紧至横滚 1°、俯仰 0.6°，对应当前实际配置。
- 排除 AI 原型、无许可记录的 board files、编译缓存、调试记录、原始人像和凭据；已有 `.bit/.hwh/.ko/.so` 作为单独运行资源附件，不提交源码 Git。
